### 💻 Sobre mí

Con experiencia en la creación de soluciones **eficientes, seguras y escalables**, me dedico a desarrollar aplicaciones modernas tanto para web como para móviles.

👨‍💻 Trabajo con lenguajes como **Java** y **Dart**, y utilizo frameworks como **Spring Boot**, **Hibernate** y **Flutter** para construir desde API REST robustas hasta aplicaciones móviles fluidas y dinámicas.

🎨 En la parte visual, creo interfaces limpias y modernas con herramientas como **Astro**, **Tailwind CSS**, **Bootstrap**, y más. Además, integro herramientas como **Figma** o **Balsamiq** para conceptualizar y mejorar la experiencia de usuario.

⚙️ Uso **metodologías ágiles** como Scrum y XP para asegurar entregas continuas y colaborativas. Versiono mis proyectos con **Git y GitHub**, manteniendo el orden en mi código.

🔐 Tengo conocimientos básicos en **ciberseguridad**, y experiencia en **OSINT** para recolección de datos públicos.
